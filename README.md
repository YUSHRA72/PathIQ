# PathIQ

### Career Guidance and Skill Development Web Application

PathIQ is a web application I'm building to help students understand their current skills and figure out what they need to improve for their desired career.

### Features
- **Career Selection:** Choose the career you want to work towards.
- **Skill Assessment:** Test your knowledge through skill-based questions.
- **Skill Gap Analysis:** Find out which skills you need to improve.
- **Personalized Roadmap:** Get a learning path based on your skill gaps.
- **Progress Tracking:** Keep track of your learning progress.
- **Project Recommendations:** Find projects related to the skills you want to improve.

### Technologies Used
- Java
- Spring Boot
- MySQL
- HTML, CSS and JavaScript
- Spring Data JPA / Hibernate
- Maven
- Git and GitHub

### How It Works
1. Create an account and choose your career goal.
2. Take skill assessments to check your current knowledge.
3. View your skill gaps and understand what needs improvement.
4. Follow your learning roadmap.
5. Track your progress and explore recommended projects.

### Aim
I started building PathIQ to create something useful for students who are unsure about which skills to learn for their target careers. I also wanted to apply what I've been learning about Java, Spring Boot, databases and frontend development in a working project.

### Current Status
The main features are being developed and connected to the backend. I plan to add more advanced AI-powered features in future updates.
